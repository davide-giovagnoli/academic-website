# Davide Giovagnoli — Academic website

A minimal academic website built with React and Vite.

## Edit your content

Open `src/data.js` on GitHub and click the pencil icon. This file contains:

- profile text and contact details;
- research interests;
- publications;
- links to ORCID, Google Scholar, arXiv, etc.

After editing, click **Commit changes**. Vercel will redeploy the website automatically.

## Replace the profile photo

Upload your photo to the `public` folder using the exact name:

`profile-photo.jpg`

## Replace the CV

Upload your PDF to the `public` folder using the exact name:

`davide-giovagnoli-cv.pdf`

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
